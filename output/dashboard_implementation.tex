\section{User Interface Implementation}
\label{sec:UIImplementation}

\begingroup
\color{black}

The primary user interface is the NAKHEL web dashboard, which allows farm personnel to monitor the infestation status of their palms, respond to alerts, and manage deployed devices. Access requires a user account, and each user sees only the organizations to which they belong. Table~\ref{tab:dashboard_screens} summarizes the implemented screens. Pages refresh automatically every 60 seconds, and a zone selector filters the displayed data by farm zone.

\subsection{\newrevision{Technology and Deployment}}
The dashboard is built with React and Next.js, using Leaflet for the map and Chart.js for charts. The complete platform is packaged with Docker Compose and is deployed on a single server. Figures~\ref{fig:dashboard_screen_sensormap}--\ref{fig:dashboard_screen_systemhealth} show the design prototypes from which the implemented screens were developed.

\subsection{\newrevision{Implementation Status}}
The dashboard, REST API, database, and worker are implemented and deployed. Several items remain before production use. The current deployment uses HTTP, so the encrypted transport required by NFR5 is still outstanding, and production email delivery has not yet been configured. The complete system test in Section~\ref{sec:complete_system_test} confirmed that a live result from one sensing node reached the dashboard through the cluster head. Multi-node operation, outage recovery, and alert delivery remain to be validated. Node battery and uptime fields stay empty until the nodes report calibrated health data.
